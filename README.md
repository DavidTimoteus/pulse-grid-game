Pulse Grid is an original neon match-and-cascade arcade puzzle. Click a group of three or more same-colour gems to pulse them; the gems above fall in and can trigger cascading combos with a rising multiplier. Chains react fast for a variable "jackpot" moment with generated sound and particle flashes. Each level shortens the clock and shuffles in new colours, so the challenge grows as you improve. Score, level, combo and remaining time are always on the HUD, with a start card and a time-up card offering an instant restart.

Play it: click a connected group of 3+ gems. SPACE starts, R restarts.

## Run it

```sh
node serve.ts          # http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
